# Everything this repo's Python runs on, and it is one line.
#
# The adapters, hooks and gates are stdlib-only on purpose: an agent hook that needs a
# virtualenv on someone else's machine does not get installed. PyYAML is the single
# exception, and only where a note's frontmatter has to come back as a mapping rather than
# as text — scripts/data-steward.py, scripts/dedup-wiki.py, scripts/vault-cleanup-gate.py
# and their tests. Splitting the frontmatter needs no parser at all (agents/shared/vault_note.py).
#
# It was undeclared until 2026-09-19 and `scripts/guard.sh` ran two suites that import it, so
# the gate was green because the CI runner image happened to ship PyYAML, not because anything
# asked for it. scripts/test_python_deps.py now fails if a second dependency appears here or in
# the source without the other side agreeing.
PyYAML>=6.0
# slack-sdk is the secretary's face only — SocketModeClient + WebClient in agents/slack/secretary.py,
# imported lazily inside main()/dispatch() so the handlers and their tests still run without the
# package. The brain (secretary_core) speaks to the engine, never to Slack, and needs nothing here.
slack-sdk>=3.27
# fastapi + uvicorn are the door's whole runtime (agents/door/door.py) — the proxy in front of
# the Rust engine: it relays the engine's contract routes and answers its own door routes.
# The door lives outside hooks/ on purpose: hooks stay stdlib-only, a door may have dependencies.
fastapi>=0.110
uvicorn>=0.29
# langgraph is the morning card's run loop (agents/slack/card.py) — one StateGraph that reads the
# engine registers, posts the Slack card, interrupts for a human verdict, and resumes on the
# button. langchain_core/langchain_ollama are the structured-output seam to the local model,
# pydantic is the card value types' language (agents/slack/card_types.py). Underscores on
# purpose: scripts/test_python_deps.py matches import names literally, and pip normalizes them anyway.
langgraph>=1.2.10
langchain_core>=1.5.3
langchain_ollama>=1.1.0
pydantic>=2.13.4
# psycopg is the door's first read of the store (agents/door/approved.py — what the morning
# card's 「해」 judged). Bare name on purpose: scripts/test_python_deps.py matches import names
# literally and knows no extra→distribution mapping; the Dockerfile installs psycopg[binary],
# the same distribution with the prebuilt driver.
psycopg>=3.2
# deepagents is agents/memory/deep_agent.py — a Deep Agent whose /memories/ is BoringStore and whose
# recall tool is BoringRetriever. It pulls 17 packages (langchain-anthropic, langchain-google-genai,
# google-genai, anthropic, …) into the same install as the morning card; none of them is called.
deepagents>=0.7.18
